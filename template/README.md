# テンプレート集

発表全体の雛形は、用途に近いMarkdownをルートの `slides.md` にコピーしてから編集してください。

| ファイル | 用途 |
|---|---|
| `basic.md` | 最小構成から始める |
| `technical-talk.md` | 5分の技術発表を組み立てる |
| [`layouts.md`](layouts.md) | 38種類のスライドから必要なレイアウトを選ぶ |
| `ai-prompt.md` | AIに初稿を生成させる |

PowerShellの例:

```powershell
Copy-Item template/technical-talk.md slides.md
```

macOS / Linuxの例:

```bash
cp template/technical-talk.md slides.md
```

コピー後はVS Codeで `slides.md` を開き、Marpプレビューで確認してください。

## レイアウトを1枚ずつ使う

1. VS Codeで [`layouts.md`](layouts.md) を開き、Marpプレビューで配置を確認します。追加レイアウトは、Markdown内の番号付きコメントから探せます。
2. 使いたいスライドの本文と `<!-- _class: ... -->` を `slides.md` に貼り、前後を `---` で区切ります。
3. 本文と画像を差し替えます。ルートの `slides.md` に貼った画像のパスは、`../assets/` から `assets/` に変えてください。

図表では文字や数値とあわせて、`style` 属性内の位置・割合と、読み上げ用の `aria-label` がある場合はその文言も更新してください。本文にあるサンプルの数値は、発表で使う計測結果に置き換えてください。

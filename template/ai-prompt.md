# AI向けプロンプトテンプレート

この文書をChatGPT、Codex、Claude、GitHub Copilot Chat、GeminiなどのAIに渡し、`[]` 内を発表内容に合わせて埋めてください。特定のAIを推奨するものではありません。生成結果は必ず人が確認してください。

## 入力

- 発表タイトル: [タイトル]
- 発表者名: [氏名・ハンドルネーム]
- 対象者: [知識レベルや所属]
- 発表時間: [例: 5分]
- 技術テーマ: [技術・プロジェクト名]
- 伝えたい結論: [一番伝えたいこと]
- 含めたい内容: [箇条書き]
- 含めない内容: [箇条書き]
- スライド枚数: [例: 8〜10枚]
- デモの有無: [あり / なし]
- コード例の有無: [あり / なし]
- 参考資料: [URL、書籍、論文、社内資料など]

## AIへの依頼文

あなたは技術発表の編集者です。上記の入力に基づき、5分発表向けの簡潔なMarp互換Markdownを生成してください。

次の条件を必ず守ってください。

1. 出力は説明文を付けず、完成したMarkdownだけにする。
2. 冒頭に次のfrontmatterを必ず含める。

   ```md
   ---
   marp: true
   theme: peachtech-ui
   size: 16:9
   paginate: true
   ---
   ```

3. スライド区切りには `---` を使う。
4. 1スライド1メッセージを基本とし、本文を詰め込みすぎない。
5. タイトル、背景、課題、提案、根拠または実装、まとめ、Q&Aを発表内容に応じて構成する。
6. 発表者が読み上げる原稿ではなく、聴衆が見て理解できる短い文を書く。
7. 不明な固有情報や数値を作らず、`[要確認: 内容]` と明記する。
8. コード例は本質が伝わる最小限の行数にする。
9. 画像が必要な箇所には、`![画像の説明](assets/ファイル名.png)` の形式で候補を置く。
10. 必要に応じて各スライド末尾のHTMLコメントにPresenter Notesを書く。
11. PeachTech UIのブランド色 `#ffffff`、`#f09dc1`、`#3fb585` と本文色 `#000000` 以外の色を追加しない。
12. 独自Markdown記法を作らない。複雑な2カラムなどに限り、既存テーマのHTMLクラスを使ってよい。

生成後、次の観点で自己確認してから最終出力してください。

- 指定した発表時間と枚数に収まっているか
- 結論が冒頭とまとめで一貫しているか
- frontmatterとスライド区切りが正しいか
- 参考資料にない事実を創作していないか

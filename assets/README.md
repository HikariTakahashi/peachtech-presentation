# 画像アセット

発表で使う画像はこのディレクトリに置き、Markdownから相対パスで参照します。

```md
![画像の説明](assets/example.png)
```

`logo.png` はスライドで標準使用するPNG版、`logo.svg` は編集用の元データです。

## ロゴのライセンス例外

`assets/logo.png` と `assets/logo.svg` はMIT Licenseの対象外です。これらのロゴは、本テンプレートを用いて作成するプレゼンテーション内でのみ利用できます。再配布、改変、商標・サービスの識別目的など、それ以外の利用は許可されません。

自分の組織や発表用にロゴを差し替える場合は、同じファイル名・サイズ感で置き換えてください。利用する画像について、著作権、ライセンス、出典表記の条件を各自で確認してください。
